# Стратегия мотивационных хуков для пользователей

> Дата: 14.03.2026
> Статус: На согласование

---

## 1. Обзор

Предлагаемая система мотивационных хуков разделена на **два сегмента** пользователей с разными целями и триггерами.

| Сегмент | Цель | Текущее состояние |
|---------|------|-------------------|
| **Обычные пользователи** | Регистрация и первый депозит у партнёра → получение PRO | Есть 3 модалки после регистрации в БК (congrats → 4ч → 24ч) |
| **PRO пользователи** (уже депнули) | Регулярные ставки у партнёра | Только PostMatch напоминание при выигрышном прогнозе |

**Проблема:** PRO пользователи после депозита практически не получают стимулов продолжать ставить. Существующий PostMatch Reminder срабатывает только когда прогноз уже зашёл — это реактивный, а не проактивный подход.

---

## 2. Сегмент А: Обычные → PRO (конверсия в депозит)

### Выбранные фразы-хуки

Из проанализированных шаблонов отобраны 5 наиболее подходящих для контекста спортивных ставок:

| № | Фраза | Тип воздействия | Где показывать |
|---|-------|-----------------|----------------|
| 1 | **«90% бетторов делают это неправильно — и вот почему»** | Провокация + авторитет | Лента матчей, перед прогнозом |
| 2 | **«Сегодня мы раскроем секрет выигрышных ставок»** | Интрига + любопытство | Push-уведомление, главный экран |
| 3 | **«Вы удивитесь, но ваши прогнозы уже могут приносить реальные деньги»** | Любопытство + мост к действию | После просмотра прогноза |
| 4 | **«У нас для вас новость: вы теряете деньги каждый день»** | FOMO (страх упущенной выгоды) | Модалка при входе в приложение |
| 5 | **«Не все ещё это поняли, но ИИ уже изменил мир ставок»** | Образование + эксклюзивность | AI-чат, экран прогнозов |

### Механика показа

- Показывать **не чаще 1 раза в день**, чтобы не раздражать
- Ротация фраз — каждый день новая
- CTA кнопка: **«Получить PRO бесплатно»** → ведёт на регистрацию у партнёра
- Дополнительно подставлять реальные цифры: «Вчера 4 из 5 прогнозов зашли»

## 3. Сегмент Б: PRO пользователи (стимуляция ставок)

### Проблема

После депозита и активации PRO пользователь получает доступ ко всем прогнозам, но **не имеет регулярных стимулов** переходить к партнёру и ставить. Единственный триггер — PostMatch Reminder после выигрышного прогноза (макс. 3 в день).

### Предлагаемые фразы-хуки

| № | Фраза | Триггер | Данные для подстановки |
|---|-------|---------|----------------------|
| 1 | **«90% бетторов упускают прибыль — и вот почему»** | Есть готовый прогноз, пользователь не перешёл к БК | Название матча, коэффициент |
| 2 | **«ИИ нашёл матч с высоким value — не пропустите»** | Появился прогноз с коэфф. > 1.8 | Матч, коэфф., тип ставки |
| 3 | **«Вы удивитесь, сколько вы упустили за эту неделю»** | Прошло 3+ дня без перехода к БК | Сумма упущенной прибыли за неделю |
| 4 | **«На этой неделе PRO прогнозы зашли в 78% матчей»** | Еженедельная сводка | Реальный % winrate за неделю |
| 5 | **«Ваш фрибет ещё ждёт — используйте его сегодня»** | Не ставил 5+ дней | Размер фрибета |

### Новый компонент: ProEngagement

Предлагается создать отдельный хук **`useProEngagement`** со следующей логикой:

```
┌─────────────────────────────────────────────────┐
│              Пользователь PRO                    │
│                     │                            │
│        ┌────────────┼────────────┐               │
│        ▼            ▼            ▼               │
│   Есть новый    Давно не     Высокий             │
│   прогноз       ставил       winrate             │
│        │        (3+ дней)    за неделю            │
│        ▼            ▼            ▼               │
│   «ИИ нашёл    «Вы упустили  «78% прогнозов     │
│    value»       €XXX»         зашли»             │
│        │            │            │               │
│        └────────────┼────────────┘               │
│                     ▼                            │
│            Мотивационная карточка                 │
│          с CTA «Поставить сейчас»                │
│                     │                            │
│                     ▼                            │
│            Переход к партнёру                     │
│           (с трекингом клика)                     │
└─────────────────────────────────────────────────┘
```

### Правила показа

| Параметр | Значение |
|----------|----------|
| Максимум показов в день | 2 |
| Минимальный интервал между показами | 4 часа |
| Ротация фраз | Случайная, без повторов подряд |
| Формат | Всплывающая карточка (bottom sheet) |
| CTA | «Поставить сейчас» → партнёрская ссылка с трекингом |
| Dismiss | «Позже» — скрывает до следующего триггера |

## 4. Точки интеграции

Хуки будут показываться в следующих местах приложения:

| Точка | Сегмент А (обычные) | Сегмент Б (PRO) |
|-------|---------------------|-----------------|
| Главный экран (Home) | Баннер с фразой + CTA | Карточка с прогнозом + CTA |
| Экран матча | «Хотите полный прогноз?» | «ИИ нашёл value — поставьте» |
| После просмотра прогноза | «Получите PRO бесплатно» | «Поставить на этот матч» |
| Push-уведомление | «Секрет выигрышных ставок» | «Не пропустите: value-матч сегодня» |
| AI-чат | Баннер внизу чата | Контекстная рекомендация |

---

## 5. Метрики успеха

| Метрика | Цель | Как измеряем |
|---------|------|--------------|
| CTR хуков (Сегмент А) | > 5% | Клики по CTA / показы |
| Конверсия в регистрацию БК | > 15% от кликнувших | Постбэк registration |
| Конверсия в депозит | > 8% от зарегавшихся | Постбэк first_deposit |
| CTR хуков (Сегмент Б) | > 8% | Клики по CTA / показы |
| Частота ставок PRO | +30% к текущей | Среднее переходов к БК в неделю |
| Retention PRO 30d | > 60% | % PRO, перешедших к БК хотя бы раз за 30 дней |

## 8. Риски и ограничения

| Риск | Митигация |
|------|-----------|
| Раздражение пользователей частыми уведомлениями | Лимит 2 показа/день, dismiss на 24ч |
| Низкий CTR отдельных фраз | A/B тестирование, ротация, замена слабых |
| Негативный отзыв на агрессивные формулировки | Избегаем токсичных шаблонов (см. отклонённые фразы) |
| Блокировка push-уведомлений | In-app карточки как основной канал |

### Отклонённые фразы (не рекомендуются)

- ~~«Вам врали про...!»~~ — слишком агрессивно, подрывает доверие
- ~~«Это худшее, что вы можете сделать»~~ — негативный фрейминг
- ~~«С развитием ИИ X нам больше не нужны»~~ — противоречит нашему продукту
- ~~«Почему большинство людей не заслуживают успеха»~~ — токсично
- ~~«Как отличить хорошего X от шарлатана?»~~ — не релевантно контексту
